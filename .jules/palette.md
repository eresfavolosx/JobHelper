## 2024-05-24 - Replace Blocking Alerts with Inline Feedback
**Learning:** Native alert() dialogs block the UI, which is especially disruptive in extension popups. Relying on them for error handling creates poor user experiences, and hardcoding fallbacks in finally blocks can lead to unused variable lint errors.
**Action:** Always replace native alerts with non-blocking inline visual feedback (e.g., temporarily updating button text/color and disabling the button). Handle success and error state resets independently within `try`/`catch` blocks, avoiding `finally` blocks when temporary UI states are used.
