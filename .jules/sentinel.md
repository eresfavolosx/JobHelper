## 2025-05-18 - Prevent Account Enumeration in Firebase Auth
**Vulnerability:** The application was directly leaking Firebase authentication error codes (e.g., `auth/email-already-in-use`, `auth/user-not-found`, `auth/wrong-password`) to the user interface during sign-up and login. This allowed an attacker to query whether an email address was registered in the database, leading to a user account enumeration vulnerability.
**Learning:** Returning explicit "Account not found" or "Email already registered" messages is a common UX pattern but a critical security flaw. The error messages should be generic and not reveal the internal state of user registration, as this data can be harvested and weaponized by attackers.
**Prevention:** Always use generic authentication error messages (e.g., "Invalid email or password", "Authentication failed. Please check your credentials or try signing in.") instead of mapping specific backend error codes directly to user-facing messages.
